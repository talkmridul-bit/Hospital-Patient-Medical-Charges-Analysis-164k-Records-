# Hospital-Patient-Medical-Charges-Analysis-164k-Records-
*164k+ Healthcare Billing Data Pipeline &amp; Dashboard ($0 OpEx)


## 📌 Executive Summary
This project delivers an end-to-end data pipeline analyzing healthcare billing efficiency, Medicare reimbursement distributions, and regional provider costs across 164,000+ patient billing records [source: 2]. Using an optimized **R (tidyverse)** ETL pipeline, raw healthcare billing data was ingested, cleaned, type-cast, aggregated, and exported into an executive dashboard—all executed under strict local hardware constraints with **$0 Cloud Infrastructure Cost ($0 OpEx)** [source: 1].

---

## 💻 Hardware & Infrastructure Constraints
* **Device:** Local Workstation (No Dedicated Cloud Server / $0 OpEx)
* **RAM:** 4 GB System Memory
* **Processor:** Intel Core i3 @ 1.20 GHz
* **Software Stack:** R (tidyverse, readxl), Tableau / PDF Dashboard Engine [source: 1, 2]
* **Dataset Volume:** ~164,000 Patient Records [source: 2]

---

## 📊 Key Business Insights & Financial Deliverables

* **Total Covered Charges vs. Total Payments:** 
  The raw hospital billing structure accumulated **$5.89 Billion** in Total Average Covered Charges, while actual settlement payments totaled **$1.58 Billion** [source: 2].
* **Medicare Coverage Gap:** 
  Total Medicare payments accounted for **$1.39 Billion** of the overall payments [source: 2]. This reveals that **Medicare covered ~87.8% of total payments**, leaving a ~12.2% gap covered by private insurance or patient out-of-pocket costs.
* **Regional Disparity (Top Market - Los Angeles):** 
  Regional breakdown highlights **CA - Los Angeles** as a primary high-cost Healthcare Referral Region (HRR) in provider billing concentration [source: 2].
